# v0.2 Portability and Public Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship version 0.2.0 with mechanically guarded Claude Code and Codex hook adapters, minimal public-repository infrastructure, clean-profile acceptance evidence, and a public GitHub release.

**Architecture:** Keep the full protocol in the canonical Agent Skill. Add one shared command-hook executable that translates Claude/Codex lifecycle payloads into existing protocol, command, planning-path, and new patch-policy decisions; native manifests and marketplaces remain thin. Preserve Pi as an independent reference adapter and label every host capability from observed acceptance results.

**Tech Stack:** Node.js 22 ESM, Node test runner, Claude Code plugin hooks, Codex plugin hooks, GitHub Actions, GitHub CLI.
